# 任務系統（含支線）

## 系統目的

提供中期目標與劇情包裝，強化世界觀代入感。

## 類型分類

- 主線：職涯里程碑（如升遷、創業）
- 支線：生活化事件（如茶水間、夜班）
- 日常：打卡、短任務

## 任務構成

- 觸發條件、目標、流程、獎勵、失敗條件

## 介面需求

- 任務列表（分類與篩選）
- 任務詳情頁（進度與獎勵）

## 參考內容

- 支線任務細節請見 [side_quests.md](../../side_quests.md)

## 數據欄位（建議）

- quest_id、quest_type、trigger
- objectives、rewards、fail_conditions
