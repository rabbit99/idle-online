## 🎮 遊戲核心機制設計

### 1. 職場體系與職涯發展

- 公家企業（系統預設）：如「世界勞動局」、「全能便利店」。門檻低、薪水穩，適合新手累積第一桶金。
- 玩家公司（創業系統）：玩家累積足夠資金後，必須先在「元宇宙房地產」購買商辦大樓才能註冊公司。
- 面試系統：雇主可設定「自動過濾條件」（如：等級、體力值）或「手動自定義問題」，增加互動樂趣。
- 管理分潤：公司老闆可決定員工薪資與抽成比例。

### 2. 放置與「打工人」日常打卡系統

- 每日登入（打卡）領取基礎體力。
- 工作任務：以「進度條式」的放置進行，不需複雜操作。
  - 文案員：放置 1 小時，產生 10 份企劃案，換取金幣。
  - 資深工程師：放置 4 小時，修復 1 個 Bug，高回報但消耗體力多。
- 摸魚機制：玩家可在工作時間選擇「摸魚」，機率性觸發隨機事件（如：獲得稀有道具或被老闆抓到扣薪）。

### 3. 資產與社會地位

- 奢侈品商店：不增加戰力，但可提升「虛榮度」或「心情值」。
  - 例：純金訂書機、虛擬超跑（停在個人檔案頁面）。
- 房地產系統：
  - 出租房：每月扣租金，若不交租會被踢到「公園長椅」睡覺。
  - 自住房：購買後可裝飾，並提升體力恢復速度。

## 📈 遊戲趣味點（亮點建議）

- 「反向雞湯」成就系統：達成如「連續加班 72 小時」、「被開除 10 次」、「存款歸零」等負面成就，可獲得特別稱號或補貼。
- 職場關係網：玩家可互加好友、查看彼此職稱（如：從「實習生」到「跨國集團總裁」），形成強烈的階級攀升視覺反差。
- 社畜聊天室：在 Jobs 版旁設立「茶水間聊天室」，讓玩家在放置等待時吐槽現實生活中的老闆。

## 🛠️ 技術實作建議

對於「還沒想好怎麼呈現」的部分，建議採用 Web-based（網頁版）作為起點。
完整實作方案請見 [遊戲開發方案](development_solutions.md)。

| 項目 | 建議方案 | 優點 |
| --- | --- | --- |
| 開發框架 | React / Vue.js + Tailwind CSS | 開發速度快，適合呈現大量文字與 UI 介面。 |
| 後端 | Node.js（Express）或 Python（FastAPI） | 處理即時打卡與數據存取。 |
| 資料庫 | PostgreSQL 或 MongoDB | 儲存玩家龐大的資產與工作紀錄。 |
| 呈現方式 | 文字放置類（PDI-like） | 成本低、擴展性強，用精美的 UI 取代 3D 建模。 |
