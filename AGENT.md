# Agent Quick Commands

## Commit & Push (current branch)
**Command:** commit-and-push-current

**Meaning:**
Stage all current git changes, create a commit with an appropriate message, and push to the current remote branch.

**Expected behavior:**
1. Check git status.
2. Stage all changes.
3. Write a concise commit message describing the change.
4. Commit and push to the current remote branch.
